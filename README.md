# OUTSIDE — Redmond 週末旅行指南

64 個約四小時圈內的城市、小鎮與旅行基地，包含 9 個加拿大目的地。資料整理日：2026-10-24。

## 開啟

macOS 可雙擊 `open.command`，或在這個目錄執行：

```bash
python3 serve.py
```

預設使用固定的 `http://127.0.0.1:62097/index.html?style=atlas`，直接開啟已選定的第二套地圖版。固定埠可保留同一瀏覽器的收藏；若該埠已在執行本指南，就沿用，不重開服務。保留啟動服務的終端機視窗，按 `Ctrl+C` 關閉。只綁定 `127.0.0.1`，不會把工作目錄或其他個人檔案公開到網路。

如果埠被其他程式占用會明確報錯，不關閉其他程式、不默默換網址。可用 `python3 serve.py --port 62098` 換埠，但不同埠的 localStorage 收藏不共用。

網站是靜態 HTML、CSS、JavaScript 與本機 JSON，不需 npm、帳號、API key 或外部 CDN。請透過本機 HTTP 網址開啟，不要直接雙擊 `index.html`，否則瀏覽器可能阻擋 JSON 讀取。

## 三種實際版型

- `index.html`：預設第二套清爽地圖版。
- `styles.html`：保留另外兩套風格與實際畫面預覽。
- `index.html?style=editorial`：暖白旅行雜誌，三欄故事卡。
- `index.html?style=atlas`：清爽地圖指南，城市列表與地圖並排。
- `index.html?style=night`：深色戶外探索，大景插畫與橫向資訊卡。

城市可深連結，例如 `index.html?style=atlas&city=snohomish`。收藏只保存在目前瀏覽器的 localStorage，不會自動跨裝置同步，換風格不會刪除。

## 內容與功能

詳細版共 481 個地點／體驗、79 條時間路線、21 條指定步道路線。每城有 6–12 個候選點，點名咖啡、餐飲、室內替代、音樂場地與季節活動；每點提供 Google Maps 搜尋，實際場所另有導航與建議停留。三個跨場地／季節節目明示須先確認當場位置，不提供虛構固定導航，也不直接插入每日時間表。時間表列出抵達、離開與轉場緩衝，音樂和列車需先確認實際日期／票務，不代表每日可直接加入。

可依小鎮、咖啡、音樂、步道、風景、爬山複選篩選（交集），也能搜尋店名或景點。各城內另可篩咖啡、餐飲、室內和步道風景、切換不同時間路線。登山另列指定入口、全程／單向距離、累計爬升、難度、規劃耗時與來源，不把平面公園和完整爬山混成一種活動。

原有地區、單程上限、季節、停留節奏、國家、雨天、推車與收藏仍保留。預設從遠到近，車程門檻採區間上緣，不採最樂觀數字。

單程時間是一般交通下的規劃估算，不是即時導航。加拿大另加過境排隊，渡輪另加候船；城市到高山、國家公園或外島的延伸需另算。票價、營業日、道路狀態與預約條件請看各目的地連結，不把本指南當即時開放系統。

## 檔案

- `cities.json`：64 個目的地的地理、車程、季節和實用背景。
- `city-guides.json`：逐城地點、店家、Google Maps 定位字串、時間路線、室內與音樂選項。
- `trails.json`：21 條指定步道的距離、爬升、入口與來源；公里／公尺由原來源單位換算，耗時是規劃估算。
- `app.js`：搜尋、篩選、排序、地圖、詳細指南與收藏。
- `styles.css`：三套版型與手機排版。
- `assets/coastline.json`：裁切後的海岸地圖。
- `previews/`：三套版型的實際桌面畫面。

所有風景插畫為原創意境圖，不是景點實景照片。海岸底圖源自 [Natural Earth](https://www.naturalearthdata.com/about/terms-of-use/) 1:50m land（public domain）；城市標記為概略位置，非停車位置或導航路線。
