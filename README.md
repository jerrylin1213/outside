# OUTSIDE — Redmond 週末旅行指南

67 個約四小時圈內的城市、小鎮與山區旅行基地（含 9 個加拿大目的地），加上 16 條一日～三日現成行程。資料整理與店家查證日：2026-10-24。

## 線上版（手機、任何網路都能開）

- 網址：https://jerrylin1213.github.io/outside/
- 原始碼：https://github.com/jerrylin1213/outside （公開 repo；內容只有旅遊資料，起點只寫到「Redmond, WA」）
- 更新方式：在本資料夾 commit 後 push 到 `main`，GitHub Pages 約 1 分鐘內自動更新。
- 線上版的收藏存在手機瀏覽器自己的 localStorage，和本機版（`127.0.0.1:62097`）互不相通。

## 店家查證狀態

咖啡、餐飲、音樂、店家與館所卡片會標示查證狀態：「已查證營業」附查證日期（看過官網或近期資訊）；尚未逐家確認的標「營業狀態尚未逐家查證」，出發前請先看 Google Maps。已確認停業的店直接移除，不留在行程裡。

## 開啟本機版

macOS 可雙擊 `open.command`，或在這個目錄執行：

```bash
python3 serve.py
```

預設使用固定的 `http://127.0.0.1:62097/index.html?style=atlas`，直接開啟已選定的第二套地圖版。固定埠可保留同一瀏覽器的收藏；若該埠已在執行本指南，就沿用，不重開服務。保留啟動服務的終端機視窗，按 `Ctrl+C` 關閉。只綁定 `127.0.0.1`，不會把工作目錄或其他個人檔案公開到網路。

如果埠被其他程式占用會明確報錯，不關閉其他程式、不默默換網址。可用 `python3 serve.py --port 62098` 換埠，但不同埠的 localStorage 收藏不共用。

網站是靜態 HTML、CSS、JavaScript 與本機 JSON，不需 npm、帳號、API key 或外部 CDN。請透過本機 HTTP 網址開啟，不要直接雙擊 `index.html`，否則瀏覽器可能阻擋 JSON 讀取。

## 三種實際版型

- `index.html`：預設第二套清爽地圖版。
- `styles.html`：保留另外兩套風格與實際畫面預覽。
- `index.html?style=editorial`：暖白旅行雜誌，三欄故事卡。
- `index.html?style=atlas`：清爽地圖指南，城市列表與地圖並排。
- `index.html?style=night`：深色戶外探索，大景插畫與橫向資訊卡。

城市可深連結，例如 `index.html?style=atlas&city=snohomish`。收藏只保存在目前瀏覽器的 localStorage，不會自動跨裝置同步，換風格不會刪除。

## 內容與功能

- **現成行程**：16 條（一日遊 7、兩日遊 6、三日遊 3），每天有出發時間、逐站時刻、停留與轉場、到家／抵達住宿時間。車程以 OSRM 路線時間加停車緩衝計算，渡輪與過境排隊用人工估算。多日行程每晚附兩間查過官網的具名住宿（含帶嬰兒的注意事項）和 Google Maps 比價連結。每天另有「整天開車路線」，因手機瀏覽器每段最多 3 個中途點，長的一天會拆段。
- **出發日判斷**：首頁行程區與城市步道區可選出發日；行程卡標示該日期是否在建議季節、是否有步道封閉，網址會帶 `date=` 方便分享。
- **城市指南**：67 個目的地、532 個地點／體驗、85 條時間路線。每個咖啡、餐飲、音樂、店家與館所卡片都標「已查證營業＋日期」與官網營業時間；已確認停業的店直接換成查證過的替代店，週末某天不開的店另附備選。
- **步道**：51 條指定路線（27 條爬山），各有距離、累計爬升、難度、規劃耗時、停車證、建議月份、冬季說明、道路季節限制與官方即時路況連結。封閉分「整條封閉」與「局部公告」，依出發日顯示。
- **篩選**：小鎮、咖啡、音樂、步道、風景、爬山複選（交集），以及地區、單程上限、季節、停留節奏、國家、雨天、推車、收藏與搜尋。預設從遠到近，車程門檻採區間上緣。

單程時間與行程車程都是規劃估算，不是即時導航。營業時間是 2026-10-24 從官網抄錄，出發前仍以官網或 Google Maps 為準；本指南沒有代訂任何餐廳、票或住宿。

## 檔案

- `cities.json`：67 個目的地的地理、車程、季節和實用背景。
- `city-guides.json`：逐城地點、店家、Google Maps 定位字串、時間路線、室內與音樂選項。
- `trails.json`：51 條指定步道的距離、爬升、入口、來源、建議月份、即時路況連結與封閉資料；公里／公尺由原來源單位換算。
- `trips.json`：16 條現成行程、住宿基地與行程用到的城外延伸點（Columbia Gorge、Cascade Loop）。
- `app.js`：搜尋、篩選、排序、地圖、詳細指南與收藏。
- `styles.css`：三套版型與手機排版。
- `assets/coastline.json`：裁切後的海岸地圖。
- `previews/`：三套版型的實際桌面畫面。

所有風景插畫為原創意境圖，不是景點實景照片。海岸底圖源自 [Natural Earth](https://www.naturalearthdata.com/about/terms-of-use/) 1:50m land（public domain）；城市標記為概略位置，非停車位置或導航路線。
